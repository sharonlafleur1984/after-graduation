# Claude skills used on this project

Read-only copies of the custom Claude skills that guide how this project is planned and built. The working versions live in Sharon's Claude account; these copies are updated whenever a skill changes.

| Skill | What it does |
|---|---|
| [product-project-manager](product-project-manager/SKILL.md) | Plans the project problem-first: a roadmap readable in 3 seconds, a researched backlog, milestones, risks and decisions. Based on Marty Cagan's *Inspired*, written for ADHD and neurodivergent readers. |
| [portfolio-frontend-build](portfolio-frontend-build/SKILL.md) | Moves a prototype built in Claude artifacts into a real repo and rebuilds it as clean, tested code: design tokens, nested components and patterns, Storybook, and a Figma loop. |
