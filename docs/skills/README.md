# Claude skills used on this project

Read-only copies of the custom Claude skills that guide how this project is planned and built. The working versions live in Sharon's Claude account; these copies are updated whenever a skill changes. Each skill reviews itself after use and suggests improvements, which Sharon approves.

| Skill | What it does |
|---|---|
| [product-project-manager](product-project-manager/SKILL.md) | Plans the project problem-first: a roadmap readable in 3 seconds, a researched backlog, milestones, risks and decisions. Based on Marty Cagan's *Inspired*, written for ADHD and neurodivergent readers. |
| [product-designer](product-designer/SKILL.md) | Designs and reviews every screen and component: Sharon's principles first, then UX laws, heuristics, WCAG 2.2, and guidance for AI and agentic interfaces. Gates what enters Storybook. |
| [portfolio-frontend-build](portfolio-frontend-build/SKILL.md) | Moves a prototype built in Claude artifacts into a real repo and rebuilds it as clean, tested code: design tokens, nested components and patterns, Storybook, and a Figma loop. |
