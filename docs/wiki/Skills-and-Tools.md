# Skills and Tools

The Claude skills and tools used on this project, and what each one does.

## Claude skills

Both live in your Claude skills list (in Claude's settings, under your saved skills).

| Skill | What it does | When it's used |
|---|---|---|
| **portfolio-frontend-build** | Moves a prototype built in Claude artifacts into a real GitHub repo, then rebuilds it as clean, tested code. Covers design tokens, nested components and patterns, matching the prototype, the Figma and Storybook loop, and a plain-language learning mode. | Any time code is being built or rebuilt |
| **product-project-manager** | Plans and organizes the project the way a strong product manager would: outcomes first, Now/Next/Later roadmap, backlog kept separate, risks and decisions logged. Based on Marty Cagan's *Inspired*, adapted for working with AI. | Roadmap, backlog, status updates |
| **working-with-sharon** | How Claude writes to Sharon: answer first, short bullets, a caveat, at most 3 options, one question at a time. | Every response, and the layout of this wiki |

## Tools

| Tool | What it's for | Link |
|---|---|---|
| GitHub | Stores the code and this wiki | [Repository](https://github.com/sharonlafleur1984/after-graduation) |
| Netlify | Hosts the live site and a preview for every pull request | Set up during the rebuild |
| Storybook | A page for every component, like a living design system | Link added once built |
| Figma | Designs, synced with the code's design tokens | Link added once connected |
| Supabase | Accounts and saved progress (later phase) | Set up when accounts are built |
