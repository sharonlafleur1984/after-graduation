# Skills and Tools

**Last updated:** October 7, 2026

The Claude skills and tools used on this project, and what each one does.

## Claude skills

The full skills, Sharon's process and project templates live in **[How I work](https://github.com/sharonlafleur1984/how-i-work)**, a separate repo shared by all her projects. The working versions of the skills live in her Claude account.

| Skill | What it does | When it's used |
|---|---|---|
| **product-engineer** | Moves a prototype built in Claude artifacts into a real GitHub repo, then rebuilds it as clean, tested code. Covers design tokens, nested components and patterns, matching the prototype, the Figma and Storybook loop, and a plain-language learning mode. | Any time code is being built or rebuilt |
| **product-designer** | Designs and reviews screens and components with Sharon's principles, UX laws, heuristics, WCAG 2.2, and AI and agentic design guidance. Reviews the words and structure of pages, including this wiki. Gates what enters Storybook. | Any design or Storybook work |
| **product-manager** | Plans and organizes the project the way a strong product manager would: outcomes first, Now/Next/Later roadmap, backlog kept separate, risks and decisions logged. Based on Marty Cagan's *Inspired*, adapted for working with AI. | Roadmap, backlog, status updates |
| **ux-writer** | Writes and reviews every word people read: plain, respectful, a little fun, and as short as clarity allows. Uses the project's [voice guide](https://github.com/sharonlafleur1984/after-graduation/blob/main/docs/voice.md). Also helps write better AI prompts. | Any copy: wiki pages, product screens, invites |
| **working-with-sharon** | How Claude writes to Sharon: answer first, short bullets, a caveat, at most 3 options, one question at a time. | Every response, and the layout of this wiki |

## Tools

| Tool | What it's for | Link |
|---|---|---|
| GitHub | Stores the code and this wiki | [Repository](https://github.com/sharonlafleur1984/after-graduation) |
| Claude Code | Builds the product on Sharon's own computer, so the app and Storybook run locally | [Claude Code](https://claude.com/claude-code) |
| Netlify | Will host the product, with a preview for every pull request | Set up while building the product |
| Storybook | A page for every component, like a living design system. Lives in the design system repo. | [Design system Storybook](https://designsystemskeleton.netlify.app/) |
| Figma | Designs, synced with the code's design tokens | Link added once connected |
| Supabase | Accounts and saved progress (later phase) | Set up when accounts are built |
| PostHog | Shows how often families log in, come back and share, for the beta ([Research Plan](Research-Plan#study-3-beta-with-accounts)) | Set up with accounts |
